# Edmund Gunn Jr. — 6G / AI-RAN / Edge AI / Digital Equality Research Portfolio

## Current research direction

Community-scale **AI-RAN, digital twins, edge measurement, and NTN resilience** for trustworthy 6G in digitally underserved communities. **Gary, Indiana** = flagship node; **7GC** = comparative scenario nodes.
